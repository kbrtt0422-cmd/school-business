# 決定 #005: Tiaful再始動ローンチプラン

- 記録日: 2026-07-03
- 記録: CEO Jobs（オーナーBIORA承認済み）
- 関連ルール: CLAUDE.md Rule #004（重要な意思決定は`operations/decisions/`に記録する）

## 背景

Tiafulはブランド名・世界観（ティアラ/シンデレラモチーフ→現行はbrand-guideline.md v1.0のCream/Gold/Deepへ刷新済み）・商品設計自体は完成していたが、過去に以下2点の実行インフラが構築できず事業として止まっていた。

1. 集客・予約システム（UTAGE）の構築
2. 動画教材の制作（撮影・編集の負荷）

営業（クローザー）の設計も不明瞭だった。価格そのものが挫折原因だったという記録はない。

## 決定事項

1. **ブランド名**: Tiaful を継続採用。既存の世界観・ビジュアル資産（brand-guideline.md準拠）をそのまま活かす。
2. **集客アカウント**: Tiaful専用の新規Instagramアカウントを開設し、BIORAが匿名・顔出しなしで運営する（既存個人アカウントとは分離し、事業売却時に資産として切り離せる形にする）。
3. **教材形式**: 撮影不要のイラストモーション＋AIナレーション形式を採用（Animaker + Canva Pro）。詳細設計は `content-production.md` を参照。
4. **広告**: Meta広告を使用する（予算あり）。テスト期は月5〜10万円、成果が見えてきたらスケール期に月30万円以上へ拡大する。詳細は `marketing-plan.md` を参照。
5. **無料相談・営業体制**: KAZU（共同代表・営業担当）はクローザー専任とし、集客活動は担当しない。集客はSara（CMO）・SNS部が担う。詳細は `organization/sales/KAZU/profile.md` を参照。
6. **価格体系**: Tiaful旧価格体系（CLASSIC 297,000円 / ROYAL 495,000円 / PREMIER 645,000円）を継承する。挫折原因が価格ではなく実行インフラだったため、市場実績のある価格をそのまま維持し、添削運用のみAI下書き＋人による最終確認方式（`grading-rubric.md`）に置き換えて工数を圧縮する。反映先: `go-to-market.md` / `marketing-plan.md` / `hearing-sheet.md` / `curriculum.md`。

## 前回との違い（挫折の再発防止）

| 項目 | 前回 | 今回 |
|---|---|---|
| 添削 | 回数無制限（人力） | 回数明示・AI下書き＋人が最終確認（`grading-rubric.md`） |
| チャット対応 | 24時間対応（人力） | 非同期テキスト添削のみ |
| 営業 | 不明（未解決） | KAZUが担当（クローザー専任、解決済み） |
| 集客・予約システム | UTAGE構築で頓挫 | MVP段階は簡易構成から着手し、後からUTAGEへ移行する方針（`content-production.md`参照） |
| 動画教材 | 撮影・編集の負荷で頓挫 | イラストモーション＋AIナレーションで撮影・編集を排除 |
